# Parveen Kumar — Digital Portfolio

## Files
- `index.html` — website content and structure
- `style.css` — design, layout and responsive styling
- `script.js` — mobile navigation and scroll animations
- `assets/` — portfolio images extracted from the supplied PDF

## How to run locally
1. Keep the folder structure unchanged.
2. Double-click `index.html` to preview the site.
3. For the best development experience, open the folder in VS Code and use the Live Server extension.

## How to publish on GitHub Pages
1. Create a GitHub repository, e.g. `parveen-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.
7. Your website will be available from the Pages URL shown by GitHub.

## Important
Replace or add images in `assets/` if you want different photographs.
Before publishing, verify all dates and wording against your latest CV.
